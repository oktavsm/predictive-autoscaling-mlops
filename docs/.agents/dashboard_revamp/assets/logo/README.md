# Ahead · original Titipin MLOps identity proposal

Original geometric T: observed interval crossbar, vertical control-plane stem, offset leading corner for the next interval. Created as SVG geometry for this kit; no icon library, font dependency, AI sparkle or traced reference mark.

Use the blue mark beside the live text “Titipin MLOps” in the product shell. The standalone outlined Titipin wordmark is available for diagrams and exports; its letterforms are original paths. This proposal does not replace an existing corporate identity or claim trademark clearance.

Clear space: 5/32 of mark height. Minimum mark: 20px; minimum outlined lockup: 110px wide. Never stretch, rotate, add glow or use decorative gradients. At 16px use a text label instead. All generic SVGs inherit currentColor when inline.

- `mark.svg`, `lockup.svg`: inherited ink.
- `*-dark.svg`: light ink for dark backgrounds.
- `*-light.svg`: dark ink for light backgrounds.
- `mark-accent.svg`: fixed blue #7DA7FF, intended for charcoal only. Use semantic accent ink for light mode.

The user-supplied PNG is visual composition reference; its angular blue logo was not copied. Preserve visible product text when using the compact original mark.

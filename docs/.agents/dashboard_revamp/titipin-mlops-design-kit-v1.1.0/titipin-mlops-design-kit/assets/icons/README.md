# Titipin operational glyphs

24 original, hand-authored glyphs. No imported icon set, emoji, AI sparkle or robot symbol.
24 × 24 viewBox; 1.7-unit stroke; square caps; miter joins. Optical size 20px in the UI, 16px for inline metadata, 24px for sparse navigation. Do not reduce below 16px.

Use `currentColor` through an inline SVG or sprite. An `<img>` does not inherit CSS `color`; for recoloring use inline SVG. For decorative use set `aria-hidden="true" focusable="false"` and remove the title. For a standalone meaningful icon add `role="img" aria-labelledby="unique-title"` plus a unique title. Icon-only controls need an accessible name on the button, not just the SVG.

`manifest.json` maps names to operational meanings. The forecast boundary, replica lanes and validation gate are the product-specific motif. Utility glyphs retain familiar geometry to avoid making common actions harder to recognize.

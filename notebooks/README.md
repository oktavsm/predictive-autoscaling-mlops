# Notebooks

This directory contains Jupyter notebooks used for Exploratory Data Analysis (EDA) and initial model prototyping.

## Planned Notebooks:
- `01_eda.ipynb` - Time-series analysis of request rates and CPU utilization.
- `02_baseline_models.ipynb` - Simple Moving Average / Persistence baseline evaluation.
- `03_model_selection.ipynb` - Evaluating potential ML models (e.g., XGBoost, LSTM).
